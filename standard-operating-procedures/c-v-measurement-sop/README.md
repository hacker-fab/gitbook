# C-V Measurement SOP

This SOP describes the general procedure for performing capacitance-voltage (C-V) measurements on semiconductor devices. It provides a common reference for measurement preparation, instrument setup, device connections, data acquisition, and safe operation.

The exact setup and measurement procedure may vary depending on the laboratory and available equipment. Follow the corresponding laboratory-specific instructions below.

* [**CMU**](cv-measurements.md)
* [**UWaterloo**](uwaterloo.md)

For the underlying theory and interpretation of C-V characteristics, see [C-V Characterization](../../metrology-and-characterization/electrical-characterization/c-v-characterization/).
