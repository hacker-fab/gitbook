# 🎥 Lithography Stepper

Lithography is a fabrication technique used to define patterns on a substrate or material layer. It is widely used in semiconductor manufacturing, microfabrication, and nanofabrication to create structures with precisely controlled geometries and dimensions.

Different lithography techniques use different methods to create and transfer patterns, depending on the required resolution, materials, and application.

This section documents lithography techniques and related equipment, including their working principles, system design, and implementation details.
